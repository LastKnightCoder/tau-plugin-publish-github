# GitHub Pages 發佈

把 Tau 裡選中的文章、卡片和專案文件發佈成一個網站，放在 GitHub Pages 上免費託管。之後改了內容，再點擊一次「發佈」就會更新，只上傳有變動的檔案。

## 三步開始

1. **裝好外掛**：在外掛中心安裝「GitHub Pages 發佈」，再裝一個部落格範本（例如「Tau 部落格」），它決定網站的外觀。
2. **填寫發佈位置**：在側邊欄開啟「發佈」，點擊「前往設定」開啟站點設定，「服務」選擇「GitHub Pages 發佈」，填寫 Token、儲存庫和部署分支。
3. **勾選內容並發佈**：在左側勾選要公開的內容，點擊「發佈」。第一次發佈後，到 GitHub 儲存庫的「Settings › Pages」把來源設為部署分支，網站就能存取了。

## 需要填寫什麼

- **Token**：GitHub 的存取權杖，需要對目標儲存庫有內容寫入權限，點擊「建立 Token」可以前往 GitHub 產生。受保護的分支仍按儲存庫規則限制推送。
- **儲存庫**：填好 Token 後可以從你的儲存庫清單裡選擇。
- **部署分支**：網站檔案放在哪個分支，例如 `gh-pages`，分支不存在時會自動建立。
- **存取路徑**：留空即可。`你的名稱.github.io` 儲存庫的網站在 `/`，其他儲存庫在 `/儲存庫名稱/`。

## 推送方式

預設使用 Git Push 推送，需要電腦上裝有 Git，還可以選一個快取目錄儲存儲存庫副本，之後的發佈更快。電腦上沒裝 Git 時，關閉「Git Push」，改用 GitHub API 逐一上傳檔案。提交者名稱和電子郵件也在「提交與推送」裡設定。

## 常見問題

**想用自己的網域？** 在儲存庫的「Settings › Pages」裡填寫網域，再把存取路徑改為 `/`、在站點設定的「公開 URL」裡填上你的網域。Tau 發佈時只更新自己產生的檔案，GitHub 產生的 `CNAME` 不會被刪掉。

**網站樣式錯亂或 404？** 多半是存取路徑不對，改完重新發佈即可。

只想把網站匯出到本機資料夾、自行部署的話，不需要安裝這個外掛，在站點設定裡選「本機匯出」。完整說明見 [發佈](https://taunote.app/docs/publish/)。
