# GitHub Pages 发布

把 Tau 里选中的文章、卡片和项目文档发布成一个网站，放在 GitHub Pages 上，免费托管。之后改了内容，再点一次「发布」就会更新，只上传有变化的文件。

## 三步开始

1. **装好插件**：在插件中心安装「GitHub Pages 发布」，再装一个博客模板（比如「Tau 博客」），它决定网站长什么样。
2. **填写发布位置**：在侧边栏打开「发布」，点「去设置」打开站点设置，「服务」选「GitHub Pages 发布」，填写 Token、仓库和部署分支。
3. **勾选内容并发布**：在左侧勾选要公开的内容，点「发布」。第一次发布后，到 GitHub 仓库的「Settings › Pages」把来源设为部署分支，网站就能访问了。

## 需要填写什么

- **Token**：GitHub 的访问令牌，需要对目标仓库有内容写入权限，点「创建 Token」可以去 GitHub 生成。受保护的分支仍按仓库规则限制推送。
- **仓库**：填好 Token 后可以从你的仓库列表里选。
- **部署分支**：网站文件放在哪个分支，例如 `gh-pages`，分支不存在时会自动创建。
- **访问路径**：留空即可。`你的名字.github.io` 仓库的网站在 `/`，其他仓库在 `/仓库名/`。

## 推送方式

默认用 Git Push 推送，需要电脑上装有 Git，还可以选一个缓存目录保存仓库副本，之后的发布更快。电脑上没装 Git 时，关掉「Git Push」，改用 GitHub API 逐个上传文件。提交者名称和邮箱也在「提交与推送」里设置。

## 常见问题

**想用自己的域名？** 在仓库的「Settings › Pages」里填写域名，再把访问路径改为 `/`、在站点设置的「公开 URL」里填上你的域名。Tau 发布时只更新自己生成的文件，GitHub 生成的 `CNAME` 不会被删掉。

**网站样式错乱或 404？** 多半是访问路径不对，改完重新发布即可。

只想把网站导出到本地文件夹、自己部署的话，不需要安装这个插件，在站点设置里选「本地导出」。完整说明见 [发布](https://taunote.app/docs/publish/)。
