# GitHub Pages 发布

在博客发布页选择此发布插件，填写连接与目标配置并保存，选择博客模板及公开内容后发布。本地导出无需安装本插件。

支持 GitHub API 和 Git Push；Token 需要对应仓库的内容写权限，受保护分支仍遵守仓库规则。Git Push 需要系统 Git；缓存目录可在表单中选择。

请使用包含博客发布提供方能力的 Tau 客户端。开发版可从本仓库 Releases 下载 ZIP，在插件页安装并主动启用；正式客户端通过插件中心安装。仅版本号为 0.59.0 不代表已包含此能力，旧构建会提示更新。

开发与构建方式见 [DEVELOPMENT.md](DEVELOPMENT.md)。
